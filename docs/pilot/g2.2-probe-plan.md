# G2.2 — Small behavioral probe plan

Date: 2026-09-02

PILOT_ONLY / NON_PRODUCTION

Question: can SP system prompt v0.1 plus a structured case payload obey the contracts without a router or new architecture?

This is a small diagnostic probe, not a benchmark. 12 of 58 trajectories, 3 repeats each, 36 runs.

## Selection criteria

Each selected trajectory can distinguish at least two of: generic prompt failure, case authoring failure, model hallucination, oracle ambiguity. Trajectories whose pass condition depends on an unresolved expert question were excluded, except where the ambiguity itself is informative.

Coverage against the required probe composition: greeting J01, reason-for-visit J03, broad invitation J04, focused symptom J07, unspecified information J10, diagnosis/hidden-test J16, examination-only J18, repeated/paraphrased P15, false premise P13, role-change/injection P22, P25 included verbatim, and J01 is the jaundice opening-overdisclosure test.

## Excluded and why

P29 needs a full station run, not a turn. J19 and P19 need an examination-action harness that does not exist yet. J25/J26 depend on unresolved clinician question 2. J13 duplicates P13's failure mode. J28 depends on unresolved SP question 4.

## Execution configuration

- Model: the primary runtime configured for this session, used for all runs. No provider comparison, no model-selection experiment.
- Generation settings: harness defaults, recorded as-run. No tuning after inspecting individual results.
- Repeats: 3 per trajectory.
- Sequencing: P14 runs before P15 within the same conversation. All others are independent single-turn conversations.
- The prompt is frozen at v0.1 for all 36 runs.

## Case payload representation

Minimal structured text derived from the contracts, containing only truth, knowledge state, disclosure eligibility, forbidden information, and uncertainty behaviour. This is a pilot fixture, not a schema. No field name here is a commitment.

## Scoring

Each run is PASS, FAIL, ORACLE_AMBIGUOUS, or EXECUTION_ERROR. Failures get one primary category and one responsible layer, per the evaluation spec. Results depending on an unresolved expert question are ORACLE_AMBIGUOUS, never forced.

## Anti-overfitting rule

A discovered failure becomes a regression trajectory. A prompt change is justified only as a general behavioral rule. Adding "do not say 120회" would be rejected.
